## Agent skills

### Issue tracker

Issues and specs are tracked in GitHub Issues via `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the five default canonical label names. See `docs/agents/triage-labels.md`.

### Domain docs

Domain docs use the single-context layout. See `docs/agents/domain.md`.

### General standards

The repository UI and user surfacing errors should be in **Polish** language.

### General testing standards

When writing unit tests each test module should target **only one** code artifact.

### Backend coding standards

When working on backend code reference `docs/agents/backend/code_standards.md`.

### Frontend coding standards

When working on frontend code reference `docs/agents/frontend/code_standards.md`.
